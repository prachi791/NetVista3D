01 / Theoretical Framework

Routing Protocol Dynamics & Trade-Offs

Analyzing the fundamental mechanisms of Distance Vector (Bellman–Ford) and Link State (Dijkstra SPF) routing.

Distance Vector Routing

Bellman–Ford Algorithm

Often described as "routing by rumor". Each router maintains a vector of estimated distances to all known destinations and periodically advertises this vector only to its directly connected neighbors.

  • Exchange Scope: Direct neighbors only (distributed computation).
  • Mathematical Rule: $D_x(y) = \min_v \{ c(x,v) + D_v(y) \}$ for neighbors $v$.
  • Trade-off: Low initial transmission overhead, but slower multi-hop propagation and susceptibility to temporary routing loops or counting-to-infinity.

Link State Routing

Dijkstra Shortest Path First

Built on global network awareness. Each router independently tests its direct link states and floods Link State Advertisements (LSAs) throughout the entire network so every node constructs an identical graph.

  • Exchange Scope: Flooded globally to all routers in the routing domain.
  • Computation: Independent local Dijkstra SPF calculation from complete LSDB.
  • Trade-off: Higher message transmission overhead during topology discovery, but rapid loop-free recovery and deterministic shortest paths.

Critical Evaluation & Methodological Limitations

1. Split Horizon Disparity: Baseline DV runs standard Bellman–Ford without split horizon (main.py:287-292), whereas DV recovery specifically applies split horizon with poisoned reverse (main.py:395-401: if old_next_hops[neighbor][destination] == node: advertised_cost = inf).

2. Non-Like-for-Like Message Units: DV counts vector advertisement events per directed link (each message carries an entire routing table), while LS counts individual LSA transmission attempts. Furthermore, LS recovery counts only changed LSAs (main.py:732). These metrics reflect implementation event counts, not raw wire byte volume or network bandwidth.

06 / Evaluation

Analysis & Trade-Off Synthesis

Scientific conclusions drawn strictly from the measured empirical results.

Equal Steps: 3 Rounds

Convergence Round Invariance

All six experimental scenarios terminated in exactly 3 synchronous rounds. The experimental data does not show that either algorithm converged faster in terms of round count.

Source: results.csv:col 3; README.md:L106
Baseline: DV 42 vs LS 50

Initial Flooding Overhead

In initial network discovery, DV produced 42 vector advertisements vs 50 for LS. Link State incurs a 19% higher message overhead initially because every router floods its LSA to all network nodes.

Source: results.csv:L2-3
Recovery: LS 16 vs DV 36

Failure Recovery Inversion

When link B–D failed, LS required only 16 changed-LSA transmissions compared to 36 for DV (a 55.6% reduction). LS flooded only the single changed link status, whereas DV re-advertised full vectors across all surviving links.

Source: results.csv:L6-7
Research Question Answer

Under matched topologies, what trade-off exists between message overhead and convergence steps?

The empirical results demonstrate a clear trade-off governed by topology dynamism: In static baseline initialization, Distance Vector produces fewer messages (42 vs 50) because information is communicated strictly among adjacent neighbors. However, during link-failure recovery, Link State achieves dramatically lower message overhead (16 vs 36) because only the two endpoints of the severed link need to originate updates, whereas Distance Vector requires every router to continue periodic vector exchanges across all active links until the entire system stabilizes.
